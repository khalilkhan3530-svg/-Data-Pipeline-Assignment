# Dataset Download Instructions

## Dataset
Online Retail Dataset

## Source
UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/352/online-retail

## License
Creative Commons Attribution 4.0 International (CC BY 4.0)

## Download Steps
1. Open the UCI dataset link.
2. Download Online Retail.xlsx.
3. Create the data/raw folder if it does not exist.
4. Place the downloaded file inside data/raw/.
5. Keep the original dataset unchanged.
6. python src/download_data.py

## Expected File Path
data/raw/Online Retail.xlsx
